🌸 Little Nest - Baby & Maternity Care StoreLittle Nest is a full-featured, single-file frontend e-commerce web application designed for baby products, nursery essentials, and maternity wear. Built with a gentle, warm aesthetic, it provides an intuitive shopping experience for parents, featuring dynamic client-side view rendering, state persistence, product filtering, shopping cart drawer, simulated user authentication, checkout, wishlist, and baby registry functionality.🎨 Design Guidelines & VibeThe website UI adheres strictly to the design specifications specified for the 💻 How to Run the ProjectClone or Download the project files.Open index.html directly in any standard modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).Alternatively, serve it via any static local development server (e.g., Live Server extension in VS Code):npx serve .
🔒 Data Persistence & StorageBecause this project is frontend-only, all application data (cart items, user profile details, wishlist, order history, and registry items) are stored locally in the user's browser using localStorage.To reset the application state to default demo data, clear the browser storage or run the following snippet in the browser Console (F12):localStorage.clear();
